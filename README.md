獨立版本，共 31 頁、25 段逐步揭曉。保留爸爸阿明與孩子的故事，以及 30 秒構思倒數。原互動版網址及檔案保留不變。

- →／Space／Page Down：先揭曉本頁下一句，再換頁。
- ←／Page Up：退回上一個步驟，再回上一頁。
- F：全螢幕；Esc：離開全螢幕或關閉對話框。
- O：總覽；Home：封面；End：結尾。
- 倒數需手動開始，可暫停、繼續、重設；離開練習頁或開啟總覽會自動暫停。
- 手機可左右滑動；橫向觀看較清楚。
- 獨立 HTML，無外部資源，不存取麥克風、不錄音、不上傳資料。
- 頁碼與揭曉步驟保存在瀏覽器 localStorage，與原版分開。
- 列印時會展開全部內容並隱藏操作列。

## Podcast 專題簡報｜原互動版

面向完全沒有經驗的新手，保留十二段演講架構，共 22 頁。

互動：第 3 頁選擇開始的障礙、第 8 頁逐張揭曉例子、第 14 頁時間膠囊、第 16 頁 30 秒構思倒數（可暫停、重設，離開頁面會暫停）。

### 操作

- 左右方向鍵／Page Up、Page Down：換頁
- F：全螢幕；Esc：離開全螢幕或關閉總覽
- O：總覽；Home：封面；End：最後一頁
- `?`：說明及重置互動
- 手機可左右滑動；互動頁有觸控操作列
- 下載 `podcast-start/index.html`，可離線開啟

不會錄音或上傳作答；目前頁碼保存在該瀏覽器的 localStorage。
